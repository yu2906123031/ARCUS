## 已完成：撤单容错

- 先读取 openOrders；没有挂单仍要确认所有本地在途订单的终态。
- 一到两笔已证明来源的挂单优先逐单 cancelOrder。
- cancelAllOrders 遇到未分类 403 或 429，重新读取订单并回退逐单撤单，批量清理暂停 60 秒。
- 未分类 403 不再永久封锁接口；明确账户、子账户、密钥、签名或时间戳拒绝仍停止。
- cancel 池 429 的退避从 10 秒开始，连续为 20 / 40 / 60 秒，并遵守更长服务端等待时间。
- 逐单与批量撤单共享取消池冷却，回退不会获得额外额度。
- 撤单与成交竞争时核对原订单；只有确认终态才释放本地暴露。未知传输结果不盲目重发。
- 清理调用通过订单修订号和锁去重。

历史日志证明了 429、403 和停机的先后关系，不能单凭这一点认定交易所网关临时封禁。新增分类日志用于继续核实交易所侧原因。

## 已完成：公平价格与库存

```text
microprice = (ask * bid_size + bid * ask_size) / (bid_size + ask_size)
OBI_L1 = (bid_size - ask_size) / (bid_size + ask_size)
fair_shift_bps = clip((microprice / mid - 1) * 10000 * weight, ±max_shift)
r = clip(position / cap, -1, 1)
inventory_shift_bps = -(k1 * r + k2 * r^3)
center = mid * (1 + (fair_shift_bps + bias_bps + inventory_shift_bps) / 10000)
```

实盘 weight=0.5、fair 偏移上限 1 bps；库存 k1=2、k2=1，接近持仓帽时库存偏移最大约 3 bps。只使用官方 BBO 的 L1 数量，未实现 L1-L5 深度模型。Microprice 已使用 L1 失衡，不重复叠加同一个方向信号。

库存减仓侧穿过盘口时夹到被动同侧 BBO；方向预算和本地防交叉继续生效。

## 已完成：成交质量 markout

实盘与 paper maker 成交都接入 1 / 3 / 5 / 10 / 30 秒评估。记录方向、成交时间、参考 mid、采样 mid、实际采样延迟、报价半价差桶、名义金额和实际手续费。

| 指标 | 定义 / 用途 |
| --- | --- |
| markout_bps | BUY 为未来 mid 相对成交价的涨幅；SELL 符号相反，包含成交价差 |
| mid_move_bps | 未来 mid 相对成交时参考 mid 的方向调整变化，用于逆向选择判断 |
| net_markout_bps | markout 扣除该笔实际手续费，返佣保留符号 |
| missing / skipped | 缺少合格未来行情 / 没有合格成交前参考行情，均不记为零 |

使用成交之前最近的合格 BBO 作参考；允许迟到成交使用已缓存的未来 BBO，但不使用成交后的行情冒充参考。默认参考和目标采样最大延迟为 1 秒。行情与待评估队列有容量上限；会话结束不额外等待 30 秒，未完成项记缺失。

恢复回放成交、重复 REST/WS 成交、taker 平仓不进入新会话 maker 样本。未知报价来源的半价差桶记 unknown，不猜测报价上下文。

新增日志事件：markout、markout_missing、markout_skipped。

## 已完成：毒性价差与 EWMA

毒性按 BUY / SELL 分开，使用最近 300 秒已完成的 5 秒 mid_move；按成交名义金额加权。每侧至少 10 个有效样本才启用，均值不利幅度超过 0.5 bps 后才产生溢价，倍率 1、最大 2 bps。每侧独立保留最近最多 2000 个已完成的 5 秒样本。

EWMA 使用 2 / 10 / 60 秒半衰期，收益平方按时间间隔归一化；输出单位 bps/√s。取三个尺度最大值估算波动，超短帧聚合，超过断流阈值重置波动状态。

实盘报价基础半价差 1.2 bps，波动倍率 1.2，通常半价差上限 4 bps：
```text
基础 = max(基础半价差, 费用底线) + 波动溢价
目标半价差[side] = 基础 + 该侧毒性溢价
```

报价还考虑当前盘口宽度；波动和毒性目标受配置上限约束，费用底线可超过上限。扩大立即生效，收窄速度最多 0.1 bps/秒，防止频繁扩缩。重挂阈值仍受 1.5 bps 上限限制。

默认通用配置保持 RMS / 毒性关闭；mm_live_btc_100.json 已选择 EWMA / 毒性开启。退出费预留比例仍为 0.25，并非预留完整 taker 退出成本。

NORMAL / FAST / TOXIC 当前只是报价状态展示，不是完整风控状态机。尚未加入毒性暂停或库存持有超时退出。扩大价差可能降低成交频率，需要结合 markout 与损益判断，不能保证提高成交额。
